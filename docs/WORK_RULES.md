# 工作规则：企微摘要到 Agent

首个规则采用“触发条件 → Agent 处理 → 人工确认”的固定结构。它在设置页配置，不占用主导航。当前只支持一条企微摘要规则；后续可以沿用相同结构扩展多条规则和其他来源。

## 当前行为

1. 在“设置 → 工作规则”选择来源 UserID、目标空间、触发前缀和处理 Agent，填写处理要求并启用。
2. 企微机器人只在收到指定 UserID 发出的、以前缀开头的文字时触发。群聊必须先将消息投递给机器人；这取决于企微及大圆的实际能力。
3. 共作按企微消息 ID 去重，保留来源 ID 和时间。摘要作为待分析资料交给所选 Agent，不附带个人记忆，也不自动引用空间资料。
4. Agent 回复保存在一项新工作中，标为“待我处理”。WorkBuddy 延迟返回时，可在工作里点击“获取最新回复”。规则不会直接修改既有任务。

## 联调顺序

1. 配置企微机器人 BotID 和 Secret，确认长连接状态为“已连接”。
2. 先用不含敏感内容的测试句给机器人发送 `日报：连接测试`，在设置页点击“检查机器人连接”，查看最近收到的发送者 UserID。这里只保留元数据，不记录未匹配消息正文。
3. 确认大圆能否主动给共作机器人发私聊，或在群里 @ 共作机器人；若不能，就需要企业允许的其他消息出口。不要假定大圆能自动转发全部聊天。
4. 将实际回调的发送者 UserID 填进规则，选择空间和 Agent，完成 WorkBuddy OAuth 授权及真实发送测试后，再启用规则。
5. 用无敏感测试摘要验证匹配、去重、Agent 回复、待确认状态和来源记录。

当前仓库只有本地模拟测试，尚无企业账号下的大圆到企微机器人到 WorkBuddy 的完整实测。规则开启后会把匹配的摘要文字交给所选 Agent；应先确认该消息范围符合团队授权。
