# 员工界面 Demo

直接用浏览器打开 `index.html` 即可查看。也可以在项目根目录运行：

```sh
python3 -m http.server 4173 --directory demo
```

然后打开 `http://127.0.0.1:4173/`。

这版原型改成了桌面 Agent 的工作界面：左上 Agent 标志负责回到主界面并开始新工作，窄图标栏负责切换上下文，会话栏按需展开，中央区域始终围绕人与 Agent 的一次工作；团队制作并发布的长期工作工具统一称为“团队小应用”。建议按这条路径体验：

1. 在首页输入目标，或点一个最佳实践把完整示例填入输入框。输入框底部的“团队 Agent”选择执行者，“工具与技能”分别展示团队技能与 MCP 接入计划。
2. 打开“给客户反馈应用增加统计页”，查看来自飞书群的消息如何自动更新任务进展，并尝试“撤销 / 重新应用”。
3. 打开“成果”，切换“预览 / 改动 / 检查”，再点击“确认发布”。
4. 点左侧“小应用”后，客户反馈管理直接显示在右侧主区域，不再弹窗；改变一条反馈的状态，再点“让 Agent 改进”返回对应工作。任务中的“成果”仍在对话右侧预览。
5. “我的工作”的“最近参与”按项目或团队空间折叠展示，点击范围后继续具体工作；“需要我”直接展示待处理项。用左侧的“工作空间”选择新工作的范围，并查看 Agent 获准使用的资料。
6. 点左侧“空间 → 新建项目”，填写名称和可选的关联团队；创建后直接进入成员步骤，可按邮箱添加待邀请同事并选择“只读”或“协作”。创建者可修改待邀请成员的预设权限。浏览器演示刷新后会清空项目；Mac 版将项目和名单保存在本机，尚未发送邀请或同步成员权限。
7. 在工作对话里输入 `@` 或点击“@ 同事”，选择演示成员并发送消息。消息会标注提及对象和“未真实送达”；当前未接入企业账号或通知服务。
8. 点左下角“设置”，在“连接与模型”中分别查看模型、执行 Agent、企业微信配置。浏览器版只预览字段；Mac 版保存后可分别测试连接。企微连接测试只验证凭据；Mac 版可从工作对话手动发送单条文字给指定 UserID，真实送达需用企业账号验证。成员同步、消息接收和项目授权仍未完成。

页面只使用浏览器内的示例数据。刷新会恢复初始状态；Agent 执行、用户登录、真实应用发布和数据持久化尚未实现。浏览器只是当前原型的承载方式，界面按独立桌面客户端设计。
